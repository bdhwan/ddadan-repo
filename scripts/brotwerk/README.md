# 브로트베르크 메뉴판 시드

브로트베르크(Brotwerk · Bakery & Coffee) 매장 디스플레이용 **빵/음료 메뉴판**
화면을 생성·갱신하는 시드.

- `menu.json` — 사장님 제공 메뉴(빵 16종 / 음료 12종, 가격 포함). 단일 출처.
- `seed_boards.py` — 어두운 배경 사진 위에 딤을 깔고, 중앙 정렬 브랜드 헤더 +
  2단 이름/가격 메뉴를 올린 1920×1080 보드 2개를 만든다(제품 이미지 없음).

## 사용법

배경 이미지는 미리 어드민(에셋)에 업로드해 두고 그 asset id를 넘긴다.

```bash
python3 seed_boards.py \
  --api http://display-1:4200/api \
  --bg-asset 18 \           # 딤 배경으로 쓸 이미지 asset id
  --bread-screen 12 \       # 생략 시 새 화면 생성
  --beverage-screen 13
```

생성/갱신된 화면을 디바이스 모니터에 할당하면(어드민 → 디바이스) 플레이어에
표시된다. display-2 = 빵, display-3 = 음료 구성이 기본.

메뉴·가격을 바꾸려면 `menu.json`만 고치고 다시 실행하면 된다(기존 화면 갱신).
